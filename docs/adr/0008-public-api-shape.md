# Public API shape: implicit transactions, pooled events, Try* beside throwing forms

The C# surface is sketched in `docs/prototype/api-sketch/` (throwaway; the implementing agents turn it into a compiling stub). Choices that a reader would otherwise question:

- **Transactions.** The primary form is a callback (`Transact`, with a state-passing overload for allocation-free static lambdas). Like JS `transact`, `Transact<TResult>(Func<Transaction, TResult>)` and the state-passing `Transact<TState, TResult>` return the callback's value. The blocking form with a timeout and cancellation token is named `TransactWithTimeout(body, origin, timeout, ct)`, not an overload of `Transact`: a `null` origin in `Transact(body, null, timeout)` would otherwise bind to the state-passing generic overload. The scoped form is a `ref struct` so it cannot cross `await`. Mutators take no transaction argument: they join the calling thread's open transaction or open an implicit one (ADR 0006).
- **Events are pooled and valid only during dispatch.** Deltas are spans, path and keys are lazy. Handlers that keep data must copy it. `Doc.Update` hands out a `ReadOnlySpan<byte>` and encodes only while subscribed. There is no owned copy of an event (no `YEvent.Snapshot()`); one is added only if users ask. `YEvent.GetPath()` is relative to `CurrentTarget`, the type whose handler is running (the deep-observer base), not to `Target`.
- **`AfterAllTransactions` passes the cleanup round's transactions.** Its handler receives `IReadOnlyList<Transaction>`, the transactions of the cycle in order (as JS passes `transactions`). The list is pooled like the events: valid only during dispatch, copy to keep.
- **Reads on an unintegrated type return the empty value**, as in JS; writes buffer as prelim content.
- **List and map content is a `YEntry`** (Any, Binary, Type, Doc), because ContentBinary and ContentAny differ on the wire. A top-level `YValue` of kind Bytes becomes Binary, as in JS.
- **Index rules.** Array and list indexes throw as JS does, text clamps, negative indexes throw. The array indexer throws where JS returns `undefined`: a recorded divergence.
- **Two further divergences.** `YXmlElement.ToString()` lowercases with the invariant culture, and resolving a root-name relative position does not create a placeholder root type.
- **Client ids are `ulong`.** `ItemId.Client`, `StateVector`, `DocOptions.ClientId`, `Doc.ClientId`, `IClientIdGenerator`, awareness client ids and `PermanentUserData` take `ulong`, matching the varuint wire. Ids and clocks up to 2^53-1 are accepted and round-trip; above that the decoder reports Malformed, where JS rounds (ADR 0003, Q12). Generated ids stay 32-bit as in Yjs. Clocks stay `long`.
- **Exposed internals.** `ItemId`, `StateVector` and `DeleteSet` are public and immutable; items and structs are not, and no read-only `ItemView` of origin, deleted flag or content kind is added: public struct identity would commit the memory layout (ADR 0018) for little user value. Tests reach structs through the `structs` dump seam. Awareness states are returned as snapshots.
- **Root and array additions.** `Doc.GetXmlText(name)` creates a root `YXmlText` (JS `ydoc.get(name, Y.XmlText)`). `YArray.Slice(start, end)` is added (negative indexes count from the end); JS `forEach` and `map` are not, since `foreach` and LINQ cover them.
- **Subdocs and undo.** `UndoManagerOptions.Doc` names the document when the initial scope is empty. `Doc.GetSubdocGuids()` returns a new set of guids. `YXmlFragment.InsertSubdoc(index, doc)` lets a fragment hold a subdoc (Yjs allows it); read it back through `Doc.Subdocs`. `Loaded` and `Synced` are events; there are no `whenLoaded`/`whenSynced` tasks.
- **Seams.** `IClientIdGenerator`, `TimeProvider` (Doc, UndoManager, Awareness) and a `Defer` hook for PermanentUserData.
- **Out of scope.** `toDOM`, async APIs (so no `whenLoaded`/`whenSynced`) and deprecated JS surface other than `Doc.ToJson` and `Destroyed`.
