# Awareness, sync and auth are specified by clock-controlled fixtures and differential tests

Extends ADR 0003, 0005, 0007, 0010, 0011 and 0012. Behaviour IDs are `AW-`, `SY-`, `AU-` from `docs/research/y-protocols.md`.

- **Scope.** All three modules: awareness (the bulk), sync read/write functions, auth message. Outside this effort: the outer sync/awareness envelope, SyncDone, read-only filtering and transport (providers). One protocol-level test is in scope: a two-peer convergence harness ported from Yjs's `TestConnector`.
- **Time seam.** Awareness takes a .NET `TimeProvider` (default `TimeProvider.System`) for both the clock and the 3000 ms check timer. Tests use `FakeTimeProvider`; the fixture `tick(ms)` step maps to `Advance`. Boundary tests pin the inclusive `>=` at exactly 15000 and 30000 ms and the 30 to 33 s effective expiry (AW-14..20).
- **Match** (golden or differential): first clock-0 message ignored (AW-43); local removal refused with clock+1 (AW-45); revival reported as `updated` and null for an absent client still reported as `removed` (AW-49); `update` versus `change` for heartbeats (AW-9, AW-50); null-to-null reports removal (AW-10); only the local clock bumps on removal (AW-26); a remote update may overwrite local state (AW-46).
- **Diverge** (`[Diverges]` test shows the JS behaviour): a bad batch applies nothing instead of partially (AW-51, per ADR 0005); `destroy` is idempotent (AW-24); encoding an id missing from meta fails through `Try*` (AW-32); `modify` returning undefined cannot occur (AW-38) and state aliasing cannot occur (AW-11), because `YValue` is immutable with no undefined (ADR 0007). `GetStates` returns a snapshot, where JS returns the same live `Map` every call (AW-13, decided: a held map never changes, the next call shows the new state). A null permission handler passed to `YAuth.TryReadMessage` throws `ArgumentNullException` at that call, before any byte is read, where JS throws a `TypeError` only when a type 0 message is reached (AU-5, decided).
- **Sync errors.** Step 2 and Update keep the contract "error handler called, no throw" (SY-8, SY-20), with the `console.error` replaced by an optional logger. A malformed Step 1 returns a failure through `Try*` instead of throwing.
- **Change filter equality.** The `change.updated` filter uses structural deep equality as `lib0` `equalityDeep` does for JSON-shaped values: object key order is ignored, nested values compare by content, a number is equal to itself, NaN is not equal to NaN, and the two zeros are equal. This is neither wire equality nor attribute equality (ADR 0007), so it is its own named comparison. Cases are pinned by fixtures.
- **Fixtures.** Ops-script steps: `awarenessNew`, `setLocalState`, `setLocalStateField`, `apply` (bytes), `removeStates`, `tick(ms)`, `destroy`. Observations: states map, meta map, ordered event log (name, payload, origin) and encoded bytes. Golden vectors cover client IDs of 2^31 or more, multibyte UTF-8, null states, empty list, duplicates, and `modifyAwarenessUpdate`. Sync and auth golden bytes, including the research's "verify" examples, are generated from the oracle, never hand-derived. The one upstream `testAwareness` is ported with `[PortOf]`.
- **Differential.** Awareness and sync join the live harness from the start. Generated awareness applies vary clocks, null states and batch order. Invariants: idempotence, highest clock wins per client, event log equal to Node's exactly.
- **Threading.** Awareness has its own lock (ADR 0006); the concurrency tests belong to that ADR's spec.
